# Meal Plan Chat Integration Guide

This document explains how to integrate meal plan creation and updates with the Ali chat interface.

## Overview

When users chat with Ali about meal plans, Ali can:
1. Ask questions to understand their dietary needs
2. Create a personalized meal plan
3. Ask for confirmation: "Do you want me to make this your active meal plan?"
4. Update the user's active meal plan when they confirm

## Database Structure

The meal plan structure is stored in Supabase with the following tables:
- `meal_plans` - Main meal plan records (one active per user)
- `meal_plan_days` - Days of the week (Monday-Sunday)
- `meal_plan_meals` - Individual meals (breakfast, snack, lunch, snack, dinner)
- `meal_plan_ingredients` - Ingredients for each meal

## Chat Integration Points

### 1. Detecting Meal Plan Conversations

In `components/AlliChatScreen.tsx`, you'll need to detect when Ali is discussing meal plans. This can be done by:
- Checking message content for keywords like "meal plan", "meal planning", "weekly meals"
- Using the AI's response to determine if it's creating a meal plan
- Storing meal plan data in conversation context

### 2. Creating Meal Plan from Chat

When Ali creates a meal plan during conversation, you need to:

1. **Parse the meal plan data from Ali's response**
   - Extract days (Monday-Sunday)
   - Extract meals for each day (5 meals per day)
   - Extract meal titles, descriptions, and ingredients

2. **Format the data** into `MealPlanDay[]` structure:
   ```typescript
   const mealPlanDays: MealPlanDay[] = [
     {
       id: 'temp-id', // Will be generated by database
       dayOfWeek: 0, // 0=Monday, 6=Sunday
       meals: [
         {
           id: 'temp-id',
           mealType: 'breakfast',
           mealOrder: 0,
           title: 'Oatmeal with Berries',
           description: 'A healthy start to your day',
           ingredients: [
             { id: 'temp-id', name: 'Rolled oats', quantity: '1', unit: 'cup' },
             { id: 'temp-id', name: 'Blueberries', quantity: '1/2', unit: 'cup' },
           ],
         },
         // ... more meals
       ],
     },
     // ... more days
   ];
   ```

3. **Store the meal plan temporarily** in conversation state or context

4. **Ask for confirmation**: When Ali finishes creating the meal plan, have her ask:
   > "I've created a personalized meal plan for you! Would you like me to make this your active meal plan?"

### 3. Handling User Confirmation

When the user responds "yes" (or similar confirmation):

1. **Detect the confirmation** in the chat
   - Check for keywords: "yes", "sure", "okay", "make it active", "use this", etc.
   - You may want to use a simple keyword check or AI classification

2. **Call the meal plan creation function**:
   ```typescript
   import { useApp } from '../contexts/AppContext';
   
   const { createMealPlanFromChat } = useApp();
   
   // When user confirms
   const handleMealPlanConfirmation = async (mealPlanDays: MealPlanDay[]) => {
     const result = await createMealPlanFromChat(mealPlanDays);
     if (result.success) {
       // Show success message
       // Optionally send a message from Ali confirming the update
     } else {
       // Show error message
     }
   };
   ```

## Notes

- The `createMealPlanFromChat` function automatically deactivates the previous meal plan
- Users can only have one active meal plan at a time
- The templated meal plan is created automatically when a user first logs in
- Users with only templated meal plans will see a prompt to chat with Ali
